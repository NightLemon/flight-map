# 公开参考数据修正与验收

实施日期：2026-09-08。范围为 GitHub Pages 的 OurAirports 公开参考版，依据 [已批准的审查报告](data-review-2026-09-08.md)。本机 FAA 资料不在本轮修改范围。

## 已实施

1. 普通跑道地图层同时检查父机场是否可显示及跑道 `closed` 标记。流亭机场旧跑道与白塔机场 `08R/26L` 不再进入普通地图；原始跑道详情和坐标继续保存，关闭跑道在详情中单独折叠显示。
2. 频率按源用途分为语音通信、导航参考和未分类。乌海 `GP 19 / 329.3 MHz` 等 8 条大陆导航频率移入导航组；无法明确识别的用途保留为未分类。相同数值的不同来源记录不合并。
3. 亳州机场英文名称改为 `Bozhou Airport`，保留原名、搜索别名和官方统计证据。所有其他待核项不改值。
4. 机场详情新增城市、类型、海拔、机场代码和官网入口；跑道展示两端编号、长宽米／英尺、表面、灯光及源关闭标记。完整性提示解释缺频率和缺端点，核查记录默认折叠。
5. 勘误绑定上游版本和预期原值，原目录逐字节公开，SHA-256 参与数据版本。发布流水线新增中国大陆严格审计。

CN 的 353 条源跑道中，119 条具有完整源端点，234 条缺完整端点。完整端点不等于可以进入普通地图；本轮再排除 2 条与关闭状态相关的记录。可显示机场仍有 342 条跑道详情，包含缺端点与源关闭记录。

独立复核遍历全部 86,053 条机场详情、48,230 条跑道、30,344 条机场频率并与固定 CSV 对比：仅亳州名称发生批准的变化；源字段、机场坐标及频率数值保留；全部频率稳定 ID 恰好出现一次。全球 14,482 个跑道瓦片要素中未发现源关闭跑道或关闭父机场。瓦片要素数量可能包含跨块重复，不能称为全球独立跑道数。

## 验证与复现

本地 Python 全回归、89 个 Web 单元测试、Python／Web lint、公开版构建、9 个 Pages 浏览器测试及 7 个原本机研究版浏览器回归均通过。Pages 回归使用真实固定数据，覆盖新名称、原值保存、关闭过滤、频率分类、按需加载、移动端布局及单指平移／双指缩放。背景底图在浏览器回归中使用合成图片，数据分片使用真实导出。

```powershell
python scripts/build_pages_data.py
python scripts/audit_mainland_reference.py --expect-reviewed --output .cache/mainland-review/post-review-audit.json
npm run build:pages
npm run test:pages
```

完整机器审计写入忽略缓存；修复前 [机器统计](mainland-data-metrics-2026-09-08.json) 保持不变。勘误内容及证据见 [目录](../reference-sources/ourairports-review.json) 和 [维护说明](../reference-sources/ourairports-review.md)。

## 尚未核实的字段

丽水、巴里坤、瑞金和亳州的定期服务标记，莫力达瓦与齐齐哈尔的长度／端点差异，以及盛乐机场建设／投用状态仍标为待核查。官方运营统计不能单独认证当前定期航班属性，端点计算也不能证明长度字段一定错误。

本轮未取得现行官方 AD 通信资料，没有补写任何缺失频率或跑道端点。修正后的社区数据仍是参考资料，核查日期不等于记录的生效日期。
